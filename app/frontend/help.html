快速开始 AI 配置 PPT 转 HTML 快速创建 对话创作 编辑与下载 常见问题

快速开始

  1. 进入首页，选择「PPT 转 HTML」「快速创建」或「对话创作」。
  2. 如果要使用 AI，请先进入「设置」配置 API Key、模型和服务商。
  3. 生成 HTML PPT 后，在预览区翻页检查，必要时进入编辑模式微调。
  4. 确认无误后下载 ZIP，压缩包会包含可翻页版和滑动版 HTML。

AI 配置

三个功能共用同一份 AI 配置。只需要在「设置」里保存一次，PPT 转 HTML、快速创建、对话创作都会自动读取。API Key 会保存在你的浏览器本地，页面再次打开时只显示脱敏状态。

1打开首页左侧「设置」，进入统一 AI 配置区。
2选择 Provider，例如 DeepSeek、Doubao Seed、OpenAI Compatible 或 Custom Workflow。
3粘贴 API Key。保存后不会明文展示，后续生成时会复用这份配置。
4确认 Model。内置服务会给出常用默认值，自定义接口需要按服务商文档填写。
5Endpoint 通常会自动填写；只有自定义模型、本地模型或工作流接口需要手动修改。
6点击 Test API 验证连接，成功后点击 Save AI / Save connection 保存。
配置项 如何填写 说明
Provider DeepSeek / Doubao Seed / OpenAI Compatible / Custom Workflow 优先选择平台内置项；如果服务商兼容 OpenAI 格式，选择 OpenAI Compatible。
API Key 粘贴服务商控制台生成的密钥 通常只显示一次，请妥善保存；余额不足也会导致生成失败。
Model 如 deepseek-chat、doubao-seed-2.0、gpt-4o-mini 必须与服务商支持的模型名称一致。
Endpoint 内置服务自动填充；自定义服务手动填写 OpenAI 兼容接口通常类似 https://api.example.com/v1。
Timeout seconds 建议 90-180 秒 长 PPT 或复杂生成可适当调高，但仍受浏览器和部署平台限制。

推荐模型怎么选？

国内网络环境下可优先尝试 DeepSeek、豆包 Doubao、智谱 GLM、通义千问 Qwen、Moonshot Kimi 等模型；国际模型可选 GPT、Claude、Gemini 等。课程 PPT 和长文档建议选择上下文更长、速度稳定、价格可控的模型。

如何接入本地模型 Ollama？

Provider 选择 OpenAI Compatible，Model 填写本地模型名，例如 qwen2.5:14b，Endpoint 填写：

http://localhost:11434/v1

连接超时或验证失败怎么办？

按顺序检查：网络是否可访问服务商、API Key 是否正确、Endpoint 是否包含正确路径、Model 名称是否存在、账户余额是否充足。如果访问国际服务较慢，需要在高级设置中使用可用的兼容地址或代理后的 Endpoint。

API Key 安全吗？

当前平台把配置保存在你的浏览器本地，用于 Test API 和生成内容时向你选择的服务商发起请求。请不要在公共电脑上保存自己的 Key；如果需要清理，可在设置中重新保存或清除浏览器站点数据。

PPT 转 HTML

适合已经有 PPT 文件，希望转成可编辑、可分享网页演示的场景。

  1. 上传 .pptx 文件，Cloudflare 线上模式建议文件不超过 50MB。
  2. 选择视觉风格。折叠状态默认展示教学蓝、学术风、瑞士网格。
  3. 选择「本地规则」或「AI 优化」。本地规则不会调用 AI。
  4. 点击生成后，在右侧预览、编辑并下载最终 ZIP。

快速创建

适合你只有主题和要求，希望 AI 直接生成完整演示稿的场景。

  1. 输入主题、受众、页数、语言、风格和补充要求。
  2. 点击 Generate HTML，AI 会直接生成可编辑 HTML PPT。
  3. 生成后可以翻页预览、进入编辑、保存修改并下载。

对话创作

适合需求还不够明确，希望 AI 像策划助手一样一步步追问、整理大纲的场景。

  1. 在输入框描述你想做的主题、受众、用途或页数。
  2. AI 会在对话框中显示「正在思考中」，并同步整理右侧页面大纲。
  3. 你可以继续补充信息，也可以直接编辑右侧每页标题、要点和视觉建议。
  4. 点击「确认并生成」后再进入 HTML PPT 生成阶段。

编辑与下载

生成结果支持文字、图片、字号、颜色、对齐和图层调整。保存后再下载 ZIP，下载内容会使用最新编辑版本。

  • Preview：打开当前翻页版 HTML。
  • Edit HTML：进入可视化编辑模式。
  • Save Edits：保存当前编辑结果。
  • Open Scroll HTML：打开上下滑动版本。
  • Download ZIP：下载最终包，包含翻页版和滑动版。

常见问题

为什么 AI 没有反应？

请先检查设置页的 API Key、模型和 Endpoint 是否正确，并点击 Test API。余额不足或服务商超时也会导致失败。

下载后图片会丢失吗？

平台会尽量把图片嵌入单文件 HTML 或放入 ZIP 资源中。分享时请发送完整 ZIP，不要只发送单独 HTML。

本地规则和 AI 优化有什么区别？

本地规则速度快、稳定，不调用外部模型；AI 优化会根据提示词重排版，但需要可用 API。
